\### 1️⃣ Linux Service \& Process Management (`systemctl` vs `service`)

\* \*\*The Concept:\*\* Explored how Linux manages background services and processes in real-world infrastructure scenarios.

\* \*\*Hands-on Commands Practiced:\*\*

&#x20; ```bash

&#x20; systemctl status docker   # Check the current state of Docker service

&#x20; systemctl start docker    # Spin up the Docker daemon

&#x20; systemctl stop docker     # Stop the Docker engine

&#x20; systemctl enable docker   # Configure Docker to start automatically on system boot

&#x20; systemctl disable docker  # Prevent Docker from starting on boot

&#x20; service docker status     # Legacy service management check

&#x20; ```
